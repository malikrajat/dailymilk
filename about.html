Dairy Hub

Record-keeping software for milk delivery businesses, with optional backup to the user's own Google Drive.

Dairy Hub is an independent personal project run by Rajat Malik. It is not a company, and anyone can create an account and use it. It is free, it does not run analytics or advertising, and it does not charge you.

Open Dairy Hub Privacy Policy

What the app does

Dairy Hub helps a milk delivery business keep its day-to-day records and turn them into reports. It is used by the owner or operator of the business, on their own device, under their own account.

  • Keep a list of milkmen (suppliers and delivery staff).
  • Record daily milk entries — quantity, shift and date.
  • Maintain milk rates and price lists.
  • Record purchases and customer payments.
  • View and export reports as CSV or PDF.

How it uses Google Drive

Google Drive is an entirely optional backup destination. It is not required to use the app. When a signed-in user chooses to connect Drive, the app requests only the scope https://www.googleapis.com/auth/drive.file.

  • The app creates a single folder named Dairy Hub Backups in that user's own Drive and writes JSON snapshots of their database into it.
  • drive.file is a per-file scope. The app can only see, create and delete files and folders that it created itself. It cannot read, list or modify any other file in the user's Drive, and it never has access to the contents of their Drive beyond its own backup folder.
  • Each user's backups live in their own Drive account. Data is never copied to a shared location owned by the developer, and users cannot see each other's backups.
  • Drive data is used only to provide the backup and restore feature the user explicitly requests. It is not used for advertising, not sold, and not transferred to third parties except as needed to provide that feature or to comply with the law, in line with the Google API Services User Data Policy, including the Limited Use requirements.
  • No Google data is stored on the developer's servers. The OAuth access token is held in the user's own browser and sent only to Google's API endpoints.
  • A user can revoke access at any time from within the app or from myaccount.google.com/permissions.

Where the rest of the data is stored

The business records themselves are stored in Google Firebase (Cloud Firestore and Cloud Storage) under the user's own account, so they are available on every device the user signs in from. Authentication is handled by Google Firebase Authentication, and the app never receives the user's Google password.
